# Services

One-line description per service. Update whenever a new service note is created.

| Service                                                    | Description                                                                                                                                                                                                                                                     |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[Zero Trust]]                                             | Strategic principle — verify explicitly, least privilege, assume breach — used to evaluate every security control.                                                                                                                                              |
| [[Conditional Access]]                                     | Entra ID policy engine that grants, blocks, or limits sign-in access based on identity, device, and risk signals.                                                                                                                                               |
| [[Cloud Adoption Framework (CAF)]]                         | Microsoft's seven-methodology roadmap for adopting and operating Azure; sequences when/how security and governance are embedded.                                                                                                                                |
| [[Microsoft Sentinel]]                                     | Cloud-native SIEM + SOAR — ingests logs, correlates incidents, automates response.                                                                                                                                                                              |
| [[Microsoft Defender]]                                     | Umbrella family of threat protection products, unified under Defender XDR.                                                                                                                                                                                      |
| [[Azure Security Logging]]                                 | Six core log sources (Activity Log, Resource Logs, VM guest logs, Storage Analytics, network flow logs, Entra ID reports) that feed centralized logging design.                                                                                                 |
| [[Logic Apps]]                                             | Serverless workflow/automation engine — the mechanism behind Sentinel SOAR playbooks.                                                                                                                                                                           |
| [[Security Posture Assessments]]                           | Continuous MCSB-benchmarked scoring of resource configuration across hybrid/multicloud, via Defender for Cloud Secure Score.                                                                                                                                    |
| [[Security Scoring Dashboards]]                            | Map of which Microsoft score (Secure Score, Advisor, Compliance Manager, Regulatory Compliance) answers which question.                                                                                                                                         |
| [[Cloud Adoption Security Review (CASR)]]                  | Checklist-driven review scoring a baseline-secured landing zone against the CAF Secure methodology; self-assessed or Microsoft-led.                                                                                                                             |
| [[Azure Landing Zones]]                                    | Multi-subscription platform + application environment (management groups, subscription vending, network topology) established in CAF's Ready phase.                                                                                                             |
| [[Azure Well-Architected Framework (WAF)]]                 | Five pillars + self-assessment for evaluating a single workload's architecture; Security pillar is WAF's SC-100-relevant piece.                                                                                                                                 |
| [[Microsoft Cybersecurity Reference Architectures (MCRA)]] | Microsoft's downloadable capability-to-Zero-Trust reference architecture deck; target-state and gap-analysis tool.                                                                                                                                              |
| [[Microsoft Cloud Security Benchmark (MCSB)]]              | Prescriptive, cross-cloud control framework (Domain → Control → Subcontrol) pre-mapped to CIS/NIST/PCI-DSS; scored via Secure Score.                                                                                                                            |
| [[Ransomware Resiliency and BCDR]]                         | Microsoft's three-phase strategy (Prepare/Limit/Prevent) treating recover-without-paying as the primary goal; backups as an attacker target.                                                                                                                    |
| [[Compliance and Privacy]]                                 | Translating regulation into controls via Purview's six compliance solutions vs. Priva's privacy-specific tools (Privacy Risk Management, Subject Rights Requests).                                                                                              |
| [[AI and Copilot Security Architecture]]                   | AI's dual architectural role — securing AI as a workload (Purview DSPM, Defender for Cloud AI-SPM, Entra Agent ID) vs. using AI as a security capability (Microsoft Security Copilot).                                                                          |
| [[Data Security Posture Management (DSPM)]]                | Two similarly-named products: Purview DSPM (data estate — M365/Azure/Fabric/SaaS) vs. Defender for Cloud data-aware security posture (cloud data stores, feeds attack paths).                                                                                   |
| [[Security Operations]]                                    | SOC architecture — combining SIEM (Sentinel), XDR (Defender), and SOAR (playbooks) via the unified platform, Sentinel workspace topology (single vs. Direct-link/Co-Management/N-Tier + Primary workspace), MITRE ATT&CK coverage across Enterprise/Mobile/ICS. |
| [[Threat Intelligence]]                                    | Sourcing/operationalizing CTI via STIX objects — Defender TI connector vs. TAXII vs. upload API — and Threat Intelligence (raw indicators) vs. Threat Analytics (curated campaign reports). MDTI converged into Defender XDR/Sentinel Aug 2026.                 |
| [[Identity as the Security Perimeter]]                     | Network perimeter → identity perimeter shift, made concrete via Global Secure Access — Entra Private Access (ZTNA/VPN replacement) vs. Internet Access (SWG) vs. Internet Access for Microsoft services (Compliant Network, Tenant Restrictions).               |
| [[Identity and Access Management (IAM)]]                   | Authorization architecture — Azure RBAC vs. Entra ID roles, managed identity vs. service principal, tenancy and directory objects (app registration vs. enterprise application), AD DS hardening.                                                              |
| [[Securing Privileged Access]]                              | Enterprise Access Model (Control/Management/Data-Workload planes) containing standing privilege — PIM (JIT activation) vs. entitlement management (bundled access) vs. CIEM (right-sizing over-provisioned permissions) vs. privileged access workstations.    |
