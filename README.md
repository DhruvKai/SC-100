# SC-100 Notes

Concise Obsidian/GitHub study notes for Microsoft's **SC-100: Microsoft Cybersecurity Architect** certification.

Written for readers who have already passed AZ-500 — see [CLAUDE.md](CLAUDE.md) for the full authoring rules.

| Folder | Contents |
| --- | --- |
| [01 Security Strategy](01%20Security%20Strategy) | Best practices, MCRA, MCSB, CAF, WAF |
| [02 Identity](02%20Identity) | Entra ID, Conditional Access, PIM, privileged access |
| [03 Infrastructure](03%20Infrastructure) | Posture management, endpoints, network security, SSE |
| [04 Applications](04%20Applications) | App security, DevSecOps, API security |
| [05 Data](05%20Data) | Data discovery, classification, encryption, AI data security |
| [06 Governance](06%20Governance) | Regulatory compliance, Azure Policy, Purview |

| [Cheat Sheets](Cheat%20Sheets) | Quick-reference tables and decision trees |
| [Diagrams](Diagrams) | Mermaid/architecture diagrams |
| [Images](Images) | Screenshots and reference images |
| [Templates](Templates) | Note and prompt templates for generating new notes |
